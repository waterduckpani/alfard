# Alfard Design System: Human-Readable Reference

## 1. Color Palette

### Light Mode
- **Background (Main)**: #FBFAF7 (primary surface)
- **Background (Secondary)**: #F6F4EF (card/surface hover)
- **Border**: #D6D1C4 (input/section borders)
- **Border (Soft)**: #E5E1D7 (dividers)
- **Text (Primary)**: #232220
- **Text (Secondary)**: #6E6960 (sub-labels)
- **Text (Tertiary)**: #908A7E (instructions/muted)

### Semantic Colors
- **Success (Green)**: #6B8E5A (bg: #ECF0E2)
- **Warning (Amber)**: #C89B4A (bg: #F6EED8)
- **Error (Red)**: #B85C5C (bg: #F4E1DE)
- **Info (Blue)**: #6F8AA8 (bg: #E3EAF1)

### Dark Mode
- **Background (Main)**: #131210
- **Background (Secondary)**: #1B1A18
- **Text (Primary)**: #E5E0D3
- **Text (Secondary)**: #A6A198

## 2. Typography
- **Headings (Satoshi)**: Bold weights (600/700). Sizes range from 40px (H1) to 16px (H4).
- **Body (Erode)**: 400 weight (Regular). Standard size: 15px. Large: 17px.
- **Scaling**: 
    - H1: 40px / 1.1 line-height
    - H2: 28px / 1.18 line-height
    - H3: 20px / 1.3 line-height
    - Body: 15px / 1.55 line-height
    - Monospace: 13px / 1.45 line-height

## 3. Spacing & Grid (4px base)
- **XS**: 4px
- **Small**: 8px
- **Medium**: 16px
- **Large**: 32px
- **XL**: 72px

## 4. UI Properties
- **Rounding (Radii)**:
    - 8px: Tiny elements (chips)
    - 12px: Interactive controls (buttons/inputs)
    - 16px: Main containers (cards/panels)
    - 999px: Pills
- **Shadows**: Soft/natural. 
    - Lvl 1 (Subtle): 1px offset
    - Lvl 3 (Popup): 8px offset
- **Motion**:
    - Fast: 140ms
    - Standard: 220ms
    - Ease: cubic-bezier(0.22, 1, 0.36, 1) to feel "soft" (ease-out).
