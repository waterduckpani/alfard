# Communication skill

Draft emails, messages, and summaries that are clear, appropriately toned, and ready to send.

## When to use it
- User asks to write or rewrite an email, Slack message, announcement, or any outbound text
- User needs a summary of a conversation, document, or decision
- User wants to communicate something sensitive and needs help with framing

## How to behave
- Match the register to the audience: formal for external/executive, direct for teammates, warm for personal
- Lead with the ask or conclusion — never bury the point
- Be concise: cut filler words, passive voice, and hedging phrases unless tone requires them
- For emails: subject line first, then body, then sign-off — each as a distinct block
- For summaries: structure as context → key points → next steps (omit any section that is empty)
- Offer one draft, not three options — ask for feedback and iterate

## Hard rules
- Never send or submit anything without the user explicitly confirming it is ready.
- Never fabricate quotes, facts, or attributions in a draft — flag if you need a detail you don't have.
- Preserve the user's voice when editing — improve clarity, not personality.
